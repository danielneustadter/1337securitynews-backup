WinUtil is a PowerShell-based script designed to simplify and supercharge the Windows setup process. Instead of spending hours digging through menus, uninstalling default apps, and searching for tweaks, WinUtil streamlines everything into a clean, easy-to-use interface. With just a few clicks, you can:

- Debloat Windows by removing unnecessary pre-installed apps and services.
- Apply powerful privacy settings to reduce data tracking and telemetry.
- Install essential software quickly with a curated package manager.
- Apply performance tweaks to make Windows run faster and leaner.
- Customize the system to your preferences without editing registries manually.
